# Trạng thái bộ ảnh

## Tổng số

- 8 ảnh demo giao diện trang web trong `screens/`.
- 32 ảnh minh họa web trong `assets/`: mỗi ngành 1 ảnh 16:9, 2 ảnh 3:4, 1 ảnh cận 4:3.
- 8 ảnh nguồn trong `source-bases/`.

## Cách sử dụng

- Các file trong `screens/` là mẫu giao diện cho Claude Code dựng layout/component.
- Các file trong `assets/` đã đúng kích thước và tên file để nối vào website.
- Ảnh Gastronomie, Bäckerei, Fleischerei và Gartenbau được phục dựng từ khu vực ảnh ngành trong mockup tổng, phù hợp prototype nhưng nên thay bằng ảnh gốc độ phân giải cao từ Drive khi có.
- Bốn ảnh ngành 07 là hình ảnh tạm thời về chuẩn bị/đánh giá hồ sơ ứng viên đại học đa ngành. Không dùng chúng để tuyên bố một chuyên ngành cụ thể.

## Quy tắc thay ảnh

Giữ nguyên tên file và tỷ lệ. Chỉ thay file khi ảnh mới: đúng bối cảnh Đức, đúng nghề, có tương tác giữa người gốc Á và đồng nghiệp Đức, không chữ, không logo thật và không sai PPE.
